# Employee Management System (EMS)

## 📌 Project Overview

Employee Management System (EMS) is a web-based application developed using PHP and MySQL.
It helps to manage employee records efficiently by reducing manual paperwork and storing data in an organized way.

---

## 🚀 Features

* User Registration & Login System
* Session-based Authentication
* Add Employee
* View Employee List
* Update Employee Details
* Delete Employee
* Dashboard for quick access
* Secure database operations

---

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Server:** XAMPP / WAMP

## ⚙️ Installation & Setup

1. Install XAMPP or WAMP
2. Move project folder to:

   ```
   C:/xampp/htdocs/
   ```
3. Start Apache & MySQL
4. Open phpMyAdmin and create a database
5. Import SQL file (`auth.sql`)
6. Update database connection in `connection.php`
7. Run project in browser:

   ```
   http://localhost/EMS
   ```
